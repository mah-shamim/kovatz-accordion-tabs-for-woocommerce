Replace WooCommerce product tabs with a modern, responsive accordion layout. Lightweight, customizable, and optimized for performance.

== Description ==

Transform your WooCommerce product pages with WooCommerce Accordion Tabs. This plugin replaces the traditional WooCommerce tabs with a sleek, responsive accordion layout that improves usability and aesthetics. Designed with simplicity and performance in mind, it’s perfect for store owners who want a modern look and feel for their shop.

== CSS and JavaScript ==

The plugin loads these assets from its `assets` directory:

* `assets/css/accordion.css` and `assets/js/accordion.js` provide the product-page accordion and tab behavior. They are loaded on product pages when the accordion is enabled.
* `assets/admin/css/kovatz-settings.css` and `assets/admin/js/kovatz-settings.js` provide styling and controls for the WooCommerce plugin settings.
* `assets/img/plus.svg` and `assets/img/minus.svg` are used by the accordion stylesheet for its expand and collapse indicators.

== Key Features ==

* Replace WooCommerce tabs with a responsive accordion layout.
* Customizable background colors, borders, icons, and padding.
* Clean and lightweight code for faster loading times.
* Fully compatible with the latest WooCommerce and WordPress versions.
* Translation-ready for multilingual stores.

= Why Choose WooCommerce Accordion Tabs? =

Accordion layouts are user-friendly, especially on mobile devices. By adopting this plugin, you enhance your store's navigation, improve user experience, and increase customer satisfaction.

== Installation ==

1. Upload the plugin to your WordPress plugin directory.
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Configure the settings under WooCommerce → Accordion Tabs.

== Frequently Asked Questions ==

= Does this plugin work with all WooCommerce themes? =
Yes, the plugin is compatible with most WooCommerce-ready themes. If you experience any display issues, you can apply custom CSS adjustments.
